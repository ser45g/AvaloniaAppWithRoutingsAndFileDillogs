# App Description

## This is an app that allows you to try out simple cyphers. It's a crossplatform app made with Avalonia UI. I just wanted to see how routing and dialogs work in such an app. In this app we can select a specific cypher, set its params to needed values and then encode/decode a message. Then we can see a graph of how our characters changed
